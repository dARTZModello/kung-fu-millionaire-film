Start Here

  1. Read the Identity Text / Canon and paste the identity text into every prompt.
  2. Keep the neon LED tube outline only style. Constants are non-negotiable.
  3. Use the character turnaround and pose sets on the main gallery as visual references when the model supports image inputs.
  4. Always generate her as an adult martial artist in dynamic poses.

Prompt Template (Image)

neon LED tube outline only style, [identity text from identity.html], [specific pose from pose set: e.g. flying kick or horse stance], [camera: close / medium / full], black background, high contrast, electric cyan and magenta, molten gold accents, HEX LAB hex patterns, dynamic energy, no solid fills, no skin

Video / Shot Notes

  • Whole-second timelines preferred for video models.
  • She is always doing something: striking, spinning, meditating with energy, collecting coins, finishing with power.
  • Lip sync only if a song is provided; otherwise silent action or music-driven.
  • Attach face / turnaround reference when available.
