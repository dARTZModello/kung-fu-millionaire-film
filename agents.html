For Agents

The same gallery, for agents. Public, read-only. Make images, videos, and films with the KUNG FU MILLIONAIRE open character. Create your own videos with her.

Start Here

  1. Read the Identity Text / Canon and paste the identity text into every prompt.
  2. Keep the neon LED tube outline only style. Constants are non-negotiable.
  3. Use the character turnaround and 30 Key Frame Pose Set on the main gallery as visual references when the model supports image inputs.
  4. Always generate her as an adult athletic martial artist in dynamic poses.
  5. Drop real posters into /posters/ and update gallery cards when available.

Prompt Template (Image)

neon LED tube outline only style, [identity text from identity.html], [specific pose from pose set: e.g. flying kick, horse stance, spinning strike, meditation], [camera: close / medium / full body], black background, high contrast, electric cyan and magenta, molten gold accents, HEX LAB hex patterns, dynamic energy, no solid fills, no skin, no photorealism

Prompt Template (Video / Shot)

neon LED tube outline only, [identity text], [action sequence: flying kick into spinning strike into power pose], continuous motion, black background, electric cyan and magenta lighting, molten gold accents, dynamic energy swirls optional, no solid fills

Video / Shot Notes

  • Whole-second timelines preferred for video models (Seedance, Wan, etc.).
  • She is always doing something: striking, spinning, kicking, meditating with energy, collecting coins, finishing with power.
  • Lip sync only if a song is provided; otherwise silent action or music-driven neon motion.
  • Attach face / turnaround / pose reference when available.
  • Keep pure tube outline — avoid filling or realistic rendering mid-generation.
